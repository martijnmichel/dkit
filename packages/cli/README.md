# @kurbo/dkit

CLI to install Directus modules (schema, permissions, flows) and Next.js UI blocks into your project.

```bash
npx @kurbo/dkit init
npx @kurbo/dkit add blog --seed
```

Docs: [dkit.run](https://dkit.run)

## Telemetry

Anonymous command usage is sent to Umami (command name, flags, CLI version — never paths, tokens, or project files). Disable with `DKIT_TELEMETRY=0`, `DO_NOT_TRACK=1`, or `dkit --no-telemetry …`.
